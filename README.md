# VacanSee 🔍

Программа для сбора и анализа вакансий с hh.ru. Сохраняет данные в JSON, позволяет фильтровать, сортировать и просматривать топ-N вакансий по зарплате.

## 🔧 Технологии
- **Python 3.12**
- Основные библиотеки:
  - `requests` — работа с API hh.ru
  - `pandas` — обработка данных для топ-N вакансий
- Тестирование:
  - `pytest`
  - `pytest-cov`
- Управление зависимостями: **Poetry**

---

## 🚀 Установка
1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/yourusername/vacansee.git
   ```
2. **Установите зависимости:**
```bash
cd vacansee
poetry install
```
## 💻 Использование
**Запустите интерактивный режим:**
```bash
poetry run python main.py
```
**Пример работы:**

1. Введите поисковый запрос (например, Python).

2. Укажите количество вакансий для вывода (например, 10).

3. Фильтруйте по ключевым словам (например, Django PostgreSQL).

## 📁 Структура проекта
```
vacansee/
├── data/                   # JSON-файлы с вакансиями
├── src/
│   ├── api.py              # Подключение к API hh.ru
│   ├── models.py           # Класс Vacancy и логика сравнения
│   ├── storage.py          # Сохранение в JSON
│   ├── utils.py            # Фильтрация и сортировка
│   └── user_interaction.py # Консольный интерфейс
├── tests/                  # Тесты (pytest)
├── main.py                 # Точка старта 
└── pyproject.toml          # Конфигурация Poetry
```

## 🧪 Тестирование

**Запуск тестов:**
```
pytest tests/ -v
```
**Покрытие:**
- Работа с API

- Валидация вакансий

- Фильтрация и сортировка

- Сохранение в JSON

**⚠️ Примечание: Проект зависит от структуры API hh.ru.
При изменениях в API требуется обновление кода.**
